# Coshop - Интернет-магазин косметики и услуг

Coshop - это современный интернет-магазин, предлагающий широкий ассортимент косметических товаров и услуг. Проект разработан с использованием React, TypeScript и Material-UI.

## Основные возможности

- Просмотр каталога товаров и услуг
- Фильтрация по категориям
- Поиск товаров и услуг
- Корзина покупок
- Личный кабинет пользователя
- Адаптивный дизайн для мобильных устройств
- Поддержка жестов для мобильных устройств

## Технологии

- React
- TypeScript
- Material-UI
- React Router
- React Swipeable

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/coshop.git
cd coshop
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект:
```bash
npm start
```
